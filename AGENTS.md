# Repository agent entry point

Before working in this repository, read and follow
[`Agents_Info/AGENTS.md`](Agents_Info/AGENTS.md).
Those instructions apply repository-wide.

Research context and history are available at:

- [`Agents_Info/RESEARCH_CONTEXT.md`](Agents_Info/RESEARCH_CONTEXT.md)
- [`Agents_Info/RESEARCH_LOG.md`](Agents_Info/RESEARCH_LOG.md) (initially empty)

Read the relevant context before research tasks and the log before continuing
prior work. References to these documents in `Agents_Info/AGENTS.md` resolve
within `Agents_Info/`; references to `papers/`, source code, and results resolve
from the repository root. Follow the current user request rather than treating
historical research plans as an active assignment.

Local source PDFs are in [`papers/`](papers/). Consult
[`papers/README.md`](papers/README.md) for the inventory. Read original papers
when implementing their constructions or citing their results. These local
files are available to agents sharing this workspace; external agents need a
copy of the repository and its PDFs.
